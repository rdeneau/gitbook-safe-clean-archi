# Welcome

This book describes in details a particular way to write a full-stack application in the .NET ecosystem, called _❝ Safe Clean Architecture ❞_. This architecture is based on a specific technical stack, explained in the next page: [motivations.md](motivations.md "mention").

A mini application called _❝ Shopfoo ❞_ accompanies this book. See the [Shopfoo](shopfoo/) chapter for more details about its features.
